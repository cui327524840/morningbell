# 晨钟 · 时政闹钟（巨魔安装 · 无需签名）

写给备考人的 iPhone 闹钟：到点必须响，响了念时间和天气，每天给你 5~10 条时政要点，平时当阅读器用。

## 功能

闹钟

- 多个闹钟，支持「仅一次 / 工作日 / 周末 / 每天 / 自定义星期几」。
- 贪睡 0~15 分钟，响铃后自动停止 5~30 分钟可调。
- 铃声可用内置闹铃，也能导入自己的 MP3 当起床音乐。
- 后台保活模式下，App 在后台、手机锁屏、静音拨片拨到静音，照样响。

起床播报（按顺序念，每项可单独开关）

1. 「现在是早上 6 点 50 分」
2. 今日时政要点前两条标题
3. 「今天北京多云，气温 12 到 20 度，当前 14 度」

每日时政要点（5~10 条）

- 每条包含：标题、分类（政治/经济/民生/法治/科技/生态/文化/外交/乡村/评论）、60~120 字要点说明、考点标签、来源与日期、原文链接。
- 点「展开要点」看完整说明，点「读原文」用内置浏览器看全文，点「标记已读」记录进度，顶部有当日已读进度条。
- 每天最多 4 条来自同一个来源、最多 4 条评论类、最多 3 条政策类，避免被单一栏目刷屏。

其他

- 天气：Open-Meteo，免费无需 key，输入城市名即可。
- 新闻流：要点之外的补充阅读，RSS 抓取 + 离线缓存，来源可自增自减。
- 设置页有诊断：机型、系统、通知权限、重要警告是否可用、保活状态、要点接口逐个镜像的连通结果。

## 每日要点是怎么来的

不直接在 App 里爬网页，也不依赖某个随时会改的第三方商业 API，而是：

```
GitHub Actions（每天 05:30 北京时间）
  抓取 10 个来源（政策文件库 / 央视 / 人民日报评论 / 新华网评 / 半月谈 / 求是 / 中新网…）
  → 按国考相关性关键词打分、近似去重、按来源与类型配额挑选
  → 取 5~10 条  →  可选：交给大模型压成要点+考点标签
  → 写入 data/digest-YYYY-MM-DD.json、data/digest-latest.json
        ↓
App 读取静态 JSON：jsDelivr → GitHub Raw → Gitee → 手机本地缓存 → 随 IPA 打包的内置快照
```

这样做的好处：App 面对的接口是静态文件，不会限流、不需要 API key、站点改版只影响 CI，
不用重装 App 就能修。三层兜底保证断网或某个镜像被封也照样有内容可读。

| 来源 | 抓取方式 | 类型 | 说明 |
| --- | --- | --- | --- |

| 央视新闻 · 要闻 / 国内 | JSON 接口 | news | 自带摘要与关键词，时效性最好 |

| 新华网评 | 列表页 | comment | 新华时评 |
| 半月谈 | 首页列表 | news | 时政解读 |
| 新华网 · 时政 | 列表页 | news | |
| 求是网 | 首页列表 | comment | 理论文章 |
| 中国新闻网 · 滚动 / 国内 | RSS | news | 带日期，稳定 |

来源全写在 [tools/sources.json](tools/sources.json) 里，可以随时增删改。JSON 接口是通用的：
写清 `list_path`（列表在 JSON 的哪个字段）和 `title_field` / `url_field` / `date_field` 等字段名即可，
换任何 OpenAI 式的接口都不用改代码。发现某个来源失效，改这个文件就行。

## 出包：最短路径

本目录**已经是一个提交好的 git 仓库**（分支 `main`，包含今天的真实要点内容），所以只要两条命令：

```bash
# 1. 先去 GitHub 网页新建一个空仓库（建议 Public，用 macOS 服务器不扣额度），不要勾选任何初始化文件
# 2. 在本目录执行（把地址换成你的）：
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

推上去之后 `build-ipa` 会**自动开始跑**，约 3~5 分钟。然后：

1. 打开仓库 → Actions → 点进 `build-ipa` 那次运行 → 页面底部 Artifacts 下载 `MorningBell-unsigned-ipa`，
   解压得到 `MorningBell-unsigned.ipa`（这就是可以装巨魔的包）。
2. 把 ipa 传到 iPhone（微信/QQ 传文件、网盘、Safari 下载都行），用文件 App 或 TrollStore 安装。
3. 打开 App → 设置 → 每日时政要点 → 要点接口 → 填「用户名/仓库名」→ 保存并更新。
4. 想更新 App 代码：改完 push 到 main，`build-ipa` 自动重跑。要点每天自动更新，不用管。

如果不想用命令行：也可以把本目录里的内容（注意包括 `.github` 隐藏文件夹）通过 GitHub 网页拖拽上传，
效果一样，只是容易漏掉隐藏文件夹。

另外 `build-digest`（每天 05:30 自动生成要点）也可以随时手动跑一次：
Actions → `build-digest` → Run workflow，它先跑离线自测，再抓取 10 个来源并把结果提交回 `data/`。
新生成的要点只有在**下一次打包**时才会被塞进 App 的离线快照里，平时 App 会自己从云端拉。

## 首次运行的验收清单

1. 允许通知权限。
2. 设置 → 诊断：机型应显示你手上这台（6s 是 `iPhone8,1`），后台保活应显示「运行中」。
3. 设置 → 天气：点「更新天气」，能显示温度说明网络和天气接口通了。
4. 时政 → 每日要点：填完仓库名后点「立即更新」，应出现当天日期与 5~10 条要点；
   「要点接口」页能看到三个镜像各自通不通，以及 10 个来源抓了多少条。
5. 设置 → 语音播报：点「试听一段播报」，能听到中文播报。
6. 真闹钟测试（最关键）：设一个两分钟后的闹钟，退到后台、锁屏、静音拨片拨到静音，等它响。

## 可选：让要点更像老师划的重点

不配置也能用（抽取式摘要：正文首段 + 分类标签）。想更进一步，在仓库里加：

- Secrets → `DIGEST_LLM_KEY`：任意 OpenAI 兼容接口的 key（DeepSeek、通义、Kimi 都行）。
- Variables → `DIGEST_LLM_BASE`（默认 `https://api.deepseek.com/v1`）、`DIGEST_LLM_MODEL`（默认 `deepseek-chat`）。

配置后生成器会把当天选出的候选交给模型，输出 60~120 字的要点说明和考点标签。
模型只允许引用候选条目的编号，链接和来源由本地代码回填，所以不会凭空编新闻或链接；
接口失败会自动退回抽取式摘要，不会让当天没有内容。

## 必须知道的限制

- 上滑强退 App、或手机重启后没打开过 App，这两种情况后台保活就没了，只能靠通知兜底：
  最长 30 秒、静音开关会挡住声音。重新打开一次 App 自动恢复。
- 保活会耗电（要一直维持音频会话），建议在 6s 和 14 上各实测一晚再决定是否常开。
- 「重要警告」能穿透静音和勿扰，但需要额外权限；设置页留了实验开关，诊断页会显示是否拿到。
- 只有巨魔安装的版本有完整能力，App Store 上架版本做不到真闹钟。

## 工程结构

| 路径 | 作用 |
| --- | --- |
| `.github/workflows/digest.yml` | 每天生成时政要点并提交回仓库 |
| `.github/workflows/build-ipa.yml` | 云端编译 + 打包未签名 IPA（顺带注入最新要点快照） |
| `tools/build_digest.mjs` | 抓取、打分、去重、配额挑选、可选大模型精炼，输出 JSON |
| `tools/sources.json` | 来源清单、关键词权重、配额与时间窗口 |
| `tools/selftest.mjs` | 离线自测（含僵尸源、双锚文本、配额等回归用例） |
| `data/` | 生成结果，已包含一份真实内容，可直接打包 |
| `Sources/Core/AlarmEngine.swift` | 闹钟调度、响铃、语音播报、贪睡、通知兜底 |
| `Sources/Core/BackgroundKeeper.swift` | 后台保活（循环静音音频） |
| `Sources/Core/Digest.swift` | 要点模型 + 多镜像/缓存/快照三层读取 + 已读进度 |
| `Sources/Core/WeatherService.swift` | 城市解析与天气 |
| `Sources/Core/NewsService.swift` | 新闻流 RSS 抓取与缓存 |
| `Sources/Core/Stores.swift` / `Models.swift` | 设置持久化与数据模型 |
| `Sources/Views/DigestViews.swift` | 要点列表（展开、已读、读原文）与接口设置 |
| `Sources/Views/*.swift` | 闹钟列表/编辑、响铃全屏、时政页、设置与诊断 |
| `Resources/digest-seed.json` | 离线内置快照（打包时会被最新要点覆盖） |
| `Resources/alarm_default.wav` | 内置闹铃音（`work/make_alarm_wav.ps1` 生成，15 秒） |
